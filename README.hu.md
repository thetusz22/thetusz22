# Szia, Martin vagyok! 👋

### 🎓 Gazdaságinformatikus BProf Hallgató @ Kodolányi János Egyetem
**Full-Stack Fejlesztő & Kreatív Technológia Szakértő**

Szenvedélyes és eredményorientált fejlesztő vagyok, akit a komplex rendszerek működése hajt – az **alacsony szintű hardvermanipulációtól** és **C#/.NET vállalati eszközöktől** kezdve a **reaktív frontend architektúrákig (React, Angular)** és az **automatizált AI munkafolyamatokig**.

Bejegyzett egyéni vállalkozóként gyártásra kész, üzleti értékű szoftvermegoldásokat szállítok, miközben a motorháztető alatt komoly K+F (R&D) projekteket fejlesztek.

### 🚀 Amit kínálok

* **🌐 Reaktív Webfejlesztés:** Skálázható, vállalati szintű felületeket építek **React** és modern **Angular (Standalone architektúra)** segítségével, szigorú TypeScript típusbiztonság mellett.

* **🤖 Munkafolyamat-Automatizáció & AI:** Intelligens munkafolyamatokat és ágenseket építek **n8n** és OpenAI/Gemini API-k segítségével, valamint strukturált **Postman automatizációs gyűjteményeket** teszteléshez.
* **🎨 Kreatív Tech & PropTech:** Híd a térbeli matematika, a **Three.js / WebGL** és a **Blender** között, amivel precíziós digitális ikreket és 3D termékkonfigurátorokat hozok létre.

### 🏆 Kiemelt Projektek

#### 1. 📬 [Post-sEmber - Angular API Kliens & Workflow Tesztelő](https://github.com/thetusz22/Post-sEmber-)
*Pehelysúlyú, fejlesztő-fókuszú reaktív webalkalmazás REST API munkafolyamatok tesztelésére.*
* **Technológia:** Angular (Standalone Components), TypeScript, RxJS (Streams & Observables), Reactive Forms, Tailwind CSS.
* **A Kihívás:** Egy elegáns, gyors alternatíva fejlesztése a nehéz asztali API kliensek helyett. Komplex állapotkezelés és dinamikus kéréstörzs-generálás implementálása tiszta RxJS streamek segítségével, az aszinkron HTTP életciklusok hibátlan kezeléséért.
* **Kulcs Skill:** Reaktív programozás & Vállalati frontend architektúra.

#### 2. 🕹️ [Hardware-Isolated Input Automation System](https://github.com/thetusz22/Hardware-Isolated-Input-Automation-System)
*Nagyteljesítményű, szoftveresen detektálhatatlan beviteli vezérlő és automatizációs rendszer.*
* **Technológia:** C#/.NET, Win32 API (P/Invoke, ReadProcessMemory), Python/MicroPython, Raspberry Pi Pico, Soros kommunikáció.
* **A Kihívás:** Egy robusztus Windows vezérlőszoftver fejlesztése, amely natív memóriaszintű diagnosztikát végez, kombinálva egy ultralacsony késleltetésű soros adatátviteli csatornával, amely a parancsokat közvetlenül hardver szintű HID emulációba csatornázza be.
* **Kulcs Skill:** Alacsony szintű rendszer-interop & Többszálú (Multi-threaded) architektúra.

#### 3. 🛡️ [Guardify - AI-Vezérelt 3D Termékkonfigurátor](https://guardify.hu)
*Full-stack e-kereskedelmi platform és egyedi gyártási csatorna.*
* **Technológia:** React, TypeScript, Vite, Three.js (React Three Fiber), Supabase, WebGL.
* **A Kihívás:** Egy éles, skálázható 3D szerkesztő felület fejlesztése pontos 3D modellekre vetítve, amely mögött egy automatizált backend ökoszisztéma kezeli a biztonságos hitelesítést (Auth) és a médiafájlok tárolását.
* **Kulcs Skill:** Kereskedelmi 3D rendszerek & Full-Stack szinkronizáció.

#### 4. 📐 [3D Térbeli Mérőeszköz & Babaház Nézet](https://github.com/thetusz22/dollhousemeasure)
*Böngésző alapú számítógépes geometriai alkalmazás PropTech elemzésekhez.*
* **Technológia:** Three.js, WebGL, Raycasting, 3D Vektormatematika, React.
* **A Kihívás:** Centiméter-pontos, valós idejű távolságkalkulációk programozása tetszőleges koordináták között egy összetett, magas poligonszámú 3D mesh környezetben.
